# mioh Remote for iPhone / iPad

mioh Remoteは、Mac版miohを同じローカルネットワークから操作・監視し、復元プレビューをHLSで視聴するiOS/iPadOSクライアントです。iPadOS 27以降の実機iPadでは、同梱したCore AIモデルを使うローカルクラスターワーカーとしても動作します。

> [!WARNING]
> 信頼できる家庭・社内のローカルLAN内だけで使用してください。制御、HLS、Worker転送にはTLSがありません。ポート転送などでインターネットへ直接公開しないでください。

## 接続方法

1. MacとiPhone/iPadを同じLANへ接続します。
2. Mac版miohで「Webリモート」を有効にします。
3. mioh RemoteがBonjourで見つけたMacを選びます。見つからない場合は`http://Macのアドレス:8888`を入力します。
4. Mac版miohに表示される12文字のアクセスコードを入力します。コードはiPhone/iPadのKeychainに保存されます。

接続後は、再生・一時停止・シーク・音量・書き出しの開始/停止と、復元済みHLS映像の視聴ができます。Mac連携はiPadの「設定」から任意で開けます。iPad単体復元にはMac接続も認証コードも必要ありません。

## iPad単体復元

iPad版はMac版に合わせた上部10タブ（基本・ブラウザ・分割・復元・検出・出力・メモリ・設定・再生・ログ）を備えます。Macへ接続せず、FilesからMP4/MOV/M4Vを選択して復元できます。BasicVSR++可変長/T18/T36/T90、検出6種、clip長、時間オーバーラップ、クロスフェード、顔限定、境界ぼかし、HEVC/H.264、ビットレートを選択できます。

「再生」タブではMac版と同じく、復元済み映像を2秒単位の再生可能な一時セグメントへ確定し、先読みしながら通常速度で再生します。ローカルファイルは「復元runner数」に応じて最大3区間を独立したCore AI runnerへ同時投入し、最大3区間の上限付き窓の中で完成順が前後しても再生順に確定します。ローカルファイルは先読み秒数で停止せず、動画末尾または空き容量の安全域まで復元済みセグメントをディスクへ蓄積します。長時間動画でもAVPlayerへ常駐させるのは最大32セグメントに留め、再生に合わせてディスクキャッシュから補充します。元動画を音声クロックに使うため音声も途切れず、シーク時は古い3 runnerの処理をすべて待って破棄してから、指定位置の新しい世代だけを復元します。再生操作の上部には直近12区間を使った並列パイプライン全体の実測処理倍率、RTF、処理fps、使用runner数を小数点以下2桁で表示します。倍率が1.00を超える（RTFが1.00未満）場合は実時間より速く、差分がディスクキャッシュへ蓄積します。再生画面右上の拡大ボタンからフルスクリーンへ切り替えられ、全画面でも再生・一時停止・シーク・処理前表示を操作できます。推論自体が動画の実時間より遅い場合は、次の復元セグメントができるまでバッファ表示になります。

「基本」タブには動画または配信ページのURLも入力できます。HTTPSのdirect HLS、静的HTML内の埋め込みページ（最大3層）、MP4/MOV/M4Vを上限付きで解析します。JavaScriptで生成されるプレイヤーやiframeは、見えないブラウザでは読み込まず、必ず上部の「ブラウザ」タブへ切り替えてユーザーに表示します。認証付きHLSの元音声と再生時計は、公開HTTPSだけを取得する端末内ループバックプロキシを通してAVPlayerへ渡します。公開ページから見つけたURLは、各requestとredirectの直前に名前解決結果も検査してLAN・loopback宛てを拒否します。認証情報は保存せず、URLのqueryやCookie値をログへ出しません。

「ブラウザ」タブは最大8層の表示中iframeとプレイヤー通信を解析します。Cloudflareなどが人による確認を要求した場合は、ユーザーが可視ページ上で通常の確認や再生操作を完了します。その同じ非永続WebKitセッションからHLS候補、HttpOnlyを含むCookie、User-Agent、安全化した参照元を取得し、既存の公開HTTPS検査を通して復元リアルタイム再生へ渡します。ブラウザのCookieはディスクやユーザーデフォルトへ保存せず、ページから得たURLを直接AVPlayerへ渡しません。別タブへ移るとページを閉じます。この機能は確認画面の自動回避ではなく、サイトが許可する通常の利用操作を同一セッションで継続するためのものです。

HLSは取得とBasicVSR++推論を分離した上限付き先読みから2秒復元キューへ渡します。ライブHLSは最近の配信区間から開始し、推論が配信に追い越された場合は元音声と復元キューを一緒にライブ端へ合わせ直します。復元用variantはiPadのメモリ上限内（最大1080p）から選びます。MP4/MOV/M4V URLは空き容量を残す転送上限を適用して端末へ取得した後、同じ復元再生へ移ります。再生操作後にだけ配信URLを生成するページは「ブラウザ」タブ内で通常どおり再生してから「配信を解析」を使います。FairPlay、AES/SAMPLE-AESなどの暗号化HLS、DRM、確認画面の自動回避には対応しません。

画面下部の「開始」を押すと、Filesへ残す全編復元を実行します。「分割」タブの「復元runner数」で1・2・3を選択でき、2または3では実フレーム境界で動画を連続区間へ分け、独立したCore AI runnerで同時に復元してから元の順序へ結合します。同じ設定をローカル動画のリアルタイム復元再生にも適用します。SFTPストリーミングやHLSなどの通信入力は、複数のデコーダが同じ通信を競合しないよう1 runnerのままです。長い動画は短縮が見込めますが、速度向上率は端末のメモリ帯域・発熱・動画条件に左右され、メモリ使用量も増えます。不安定な場合は1または2へ下げてください。Macから使うiPad Workerは1ジョブずつ処理します。復元中は先頭区間の書き込み済みフレームを「再生」タブで確認でき、完成後は時刻スライダー付きの通常プレイヤーで音声付きMP4を再生できます。処理後は元動画の音声を復元映像へ再結合し、共有シートからFilesまたは写真へ保存します。完成ファイルはFilesの「このiPad内 > mioh Remote」に残ります。

### SFTP入出力

「基本」の「SFTPから動画を選択」では、ホスト、ポート、ユーザー名、パスワードを指定してサーバー内のフォルダを参照し、MP4/MOV/M4VをiPadへダウンロードして単体復元の入力にできます。一覧の情報ボタンを押すと、動画全体を保存せずに必要なbyte rangeだけを読み、長さ・解像度・fps・コーデック・音声有無・平均データレートを確認できます。確認済みの主要情報はその接続中の一覧にも表示します。完成したダウンロードはFilesの「このiPad内 > mioh Remote > SFTP Downloads」に元のファイル名で保存し、同名がある場合は番号を付けて上書きを避けます。入力を解除しても自動削除しません。転送中の部分ファイルはFilesへ露出しないApplication Support内に最大30日保持し、再接続後に同じサーバー・ユーザー・信頼済みホスト鍵・リモートパスの動画を選ぶと、検証済みoffsetから残りだけを取得します。30日を超えた再開用ファイルは次回起動時に上限件数つきで削除します。リモートのサイズまたは更新時刻が変わっていた場合は古い部分を破棄して先頭から取得し、完成後だけFilesへ移動します。動画を長押しすると「ダウンロード」と「ストリーミングで復元再生」を選択できます。通常のタップは従来どおりダウンロードです。ストリーミングは専用の鍵固定済みSFTP接続からAVFoundationが要求したbyte rangeだけを取得し、最大4ページをrequest IDで並列処理します。シークで不要になった待ち手だけを切り離し、すでに送信済みの最大4ページは完了後にキャッシュするため、古い1要求が次のシークを直列に塞ぎません。再生操作の上部にはSFTPの実効bps、Range並列数、直近の応答時間、復元RTF、現在待っている工程を表示します。復元RTFが1.00を超える状態では復元処理自体が実時間に追いつかず、ネットワークが速くてもバッファ切れが起こり得ます。原動画を端末へ全量保存せずに開始できますが、全編再生時の通信量は原動画全体に近づく場合があります。全編MP4を書き出す場合はダウンロードを選択してください。

復元完了後は「出力」の「完成MP4をSFTPへ送信」から、現在のフォルダへ完成動画をアップロードできます。同名ファイルは上書きせず、転送中は`.part`相当の一時名を使い、完了後だけ確定名へ変更します。

初回接続ではSSHホスト鍵のSHA-256フィンガープリントを表示します。接続先の管理者に確認してから信頼してください。保存した鍵と次回の鍵が異なる場合は接続を拒否し、再信頼には保存済みホスト鍵の明示的な削除が必要です。パスワードと信頼済みホスト鍵は専用Keychainへ保存し、UserDefaultsやログへは残しません。ホスト名、ポート、ユーザー名、最後のフォルダだけを接続設定として保存します。

ダウンロードとストリーミング対象は20 GiBを上限とし、ダウンロード時は既存の部分ファイルを考慮した上でiPadの空き容量を最低1 GiBまたは10%残します。リモートパスの各要素を`LSTAT`で確認してシンボリックリンクを拒否し、ダウンロードの開始・再開・完了時とストリーミング中はopen handleのサイズと更新時刻を`FSTAT`で再確認します。SFTP v3では同一サイズ・同一更新秒内の書換えを完全には検出できません。通信失敗・キャンセル・バックグラウンド猶予切れ時のダウンロード部分は安全な再開情報とともに保持します。アプリがバックグラウンドへ移っても即切断せず、iOSが許可する有限のバックグラウンド実行時間は転送を継続します。OSの猶予が終了した場合は接続を閉じ、次回選択時に再開します。画面ロックで保護データが利用不能になる場合と明示的な切断では直ちに接続を閉じます。SFTPはURLSessionのバックグラウンド転送ではないため、長時間のバックグラウンド完走は保証しません。認証はパスワード方式、ホスト鍵はEd25519またはECDSAに対応します。公開鍵・keyboard-interactive認証やRSAのみの古いサーバーには対応しません。

App Storeへ配布する際は、SSH暗号機能の追加に伴う輸出コンプライアンスの回答をリリース手順で再確認してください。

単体復元はCore AIを利用するため、iPadOS 27以降の実機iPadが必要です。iOS Simulatorでは設定画面とファイル選択を確認できますが、Core AI推論は開始できません。

## iPad Worker

「Workerを開始」を押し、mioh Remoteを前景のまま維持します。Mac版miohは同じLAN上のWorkerを自動検出して接続するため、認証コードの入力はありません。

通常はMacが短命な専用HTTP Range URLで入力を配信し、iPadが完成shardをストリーミングPUTで返します。iPadが元動画をSMBから直接読む必要はありません。SMB共有rootは、MacとiPadのFilesから同じ共有フォルダを参照できる場合だけ使用する予備経路です。

Workerは入力・出力が同一HTTPオリジン、同一チケット、固定Capabilityパスであることを検証します。別ホスト/別ポート、HTTPS、userinfo、query、fragment、パス偽装を含むジョブは拒否します。

WorkerはMP4/MOV/M4V、BasicVSR++ T18/T36/T90と可変長Core AI、検出v2/v3.1-fast/v3.1-accurate/v4-fast/v4-accurate/VR-v2-accurate、同時1ジョブ、最大90フレームに対応します。可変長モデルは11個のCore AI関数をMetal共有バッファ上で順次実行します。4個のcontinuation関数は`state_n1`、`state_n2`、`flow_previous`をCore AI native stateとして保持し、旧explicit-I/O資産もランナー側で自動判別して実行できます。ROIエンハンサーと復元後エフェクトには対応しません。iPadOSのバックグラウンド実行制限に従い、画面ロックまたはアプリのバックグラウンド移行で停止します。

Coordinator Mac側で、iPadがBonjour capabilityとして通知する上記モデルを選択します。異なるモデル、90を超えるclip長、ROIエンハンサーまたは復元後エフェクトを含むジョブはiPadへ配布されません。

## Build

`MiohRemote.xcodeproj`を開き、共有Scheme `MiohRemote`を選択してiOS 16以降の端末で実行します。リモート操作はiPhone/iPadで利用できます。SFTP機能はローカルSwift packageの`MiohSFTPKit`と、監査済みのvendored SFTP v3 parser、固定版のSwiftNIO/SwiftNIO SSHを使用します。依存packageの解決にはSwift 6.1以降を含むXcodeが必要です。受信frame・一覧件数・拡張属性件数には割り当て前の上限検査があります。依存ライセンスは[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)とアプリ同梱の`ThirdPartyLicenses`を参照してください。Worker機能のビルドにはXcode 27 SDK、実行にはiPadOS 27以降の実機iPadが必要です。可変長モデルのsource資産はmacOS standalone buildが`--native-state-continuations`付きで生成する`build/macos-standalone/variable-basicvsrpp-source`、M5実機向け事前コンパイル資産は`build/ios-coreai-h17g`をXcodeが同梱します。どちらも生成物のためGitには含めません。AVFoundationの読み書きはiOS 26以降で非同期receiver/provider APIを使い、iOS 16〜25では互換経路へ切り替わります。
