# v4-fast Core ML Postprocess Contract

## Model

`lada_mosaic_detection_model_v4_fast.mlpackage` is exported from
`model_weights/lada_mosaic_detection_model_v4_fast.pt` by
`scripts/apple/export_v4_fast_coreml.py` (`nms=False`, `half=False`,
`imgsz=640`). The raw YOLO11 segmentation outputs are preserved so native
code owns the full postprocess.

## Core ML Interface

- Input: `image`, RGB, `640x640`
- Output candidates: shape `1 x 38 x 8400`, float32
- Output prototypes: shape `1 x 32 x 160 x 160`, float32

The output names (`var_1324`, `var_1362` in the current export) are
generated by the converter and may change between exports. Identify the
outputs by shape: the rank-3 tensor is the candidate tensor, the rank-4
tensor is the mask prototype tensor.

## Candidate Tensor Layout

Each of the 8400 columns in `1 x 38 x 8400` is one candidate:

| Channels | Content |
| --- | --- |
| 0..3 | box center `cx`, `cy`, width `w`, height `h` in 640x640 network pixels |
| 4..5 | per-class confidence scores (already sigmoided) |
| 6..37 | 32 mask coefficients for the prototype tensor |

## Classes

- `0`: `mosaic_nsfw`
- `1`: `mosaic_sfw_head`

## Native Postprocess Requirements

The reference implementation is `Yolo11SegmentationModel` in
`lada/models/yolo/yolo11_segmentation_model.py`.

1. Apply YOLO letterbox preprocessing to `640x640`, stride `32`: scale the
   image preserving aspect ratio, center it, pad with gray `114`. The Core ML
   input is fixed at `640x640`, so pad to the full square (LADA's PyTorch
   path may use rectangular stride-aligned padding, which is why small box
   deltas against PyTorch are expected and tolerated by the parity
   thresholds).
2. Normalize RGB pixels to `0...1` (divide by `255.0`).
3. Decode the candidate tensor into boxes (`cxcywh` to `xyxy`), class
   scores, and 32 mask coefficients.
4. Apply confidence threshold on the best class score, default `0.25`.
5. Apply class-aware NMS, default IoU `0.7`, matching
   `ultralytics` `non_max_suppression` with `agnostic=False`.
6. Multiply the selected mask coefficients (`N x 32`) by the prototype
   tensor (`32 x 160 x 160`) to get `N x 160 x 160` mask logits.
7. Apply sigmoid to the mask logits.
8. Crop each mask to its (downscaled) box.
9. Upsample masks bilinearly to the `640x640` network image and threshold
   at `0.5` (matches `ops.process_mask(..., upsample=True)`).
10. Undo letterbox padding and scale boxes/masks to original image
    coordinates (matches `ops.scale_boxes`).
11. Drop detections whose mask has zero area.

## Parity Notes

Default parity thresholds, from `scripts/apple/validate_v4_fast_coreml.py`:

- box max absolute coordinate difference `<= 4.0 px`
- confidence absolute difference `<= 0.02`
- class ids: exact match
- detection count at `conf=0.25`: exact match
- mask area relative difference `<= 10%`

The native implementation must be validated against
`scripts/apple/validate_v4_fast_coreml.py` before being used by a
macOS/iOS runtime.
