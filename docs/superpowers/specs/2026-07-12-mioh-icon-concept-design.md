# mioh Icon Concept Design

## Goal

Create a preview image for a new `mioh` app icon based on a custom lowercase wordmark.

## Mark construction

- The readable base is lowercase `mio`.
- The `i` and lowercase `h` share the same vertical stem.
- Keep the `i` dot visible so `mio` remains legible.
- Add only the shoulder and right stroke of `h` over the `i`, producing a compact `i/h` ligature.
- Avoid making the overlay look like an unrelated fourth letter placed after `mio`.

## Visual direction

- Minimal, geometric, vector-friendly logo treatment.
- Dark charcoal mark on a soft light-gray macOS icon field.
- Centered, generous padding, strong silhouette at small sizes.
- No gradients, shadows, 3D effects, decorative objects, watermark, or additional text.

## Deliverable

- One square preview image generated with the built-in image generation tool.
- This first image is exploratory and does not replace the current app icon automatically.
- After visual approval, prepare a production icon asset and integrate it into the macOS build separately.
