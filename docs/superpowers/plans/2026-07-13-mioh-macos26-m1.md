# mioh macOS 26 M1 Compatibility Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make one mioh app launch and process video on an M1 Mac with macOS 26 while retaining CoreAI acceleration on macOS 27 and newer.

**Architecture:** Compile the SwiftUI app for macOS 26 without linking CoreAI, but retain a separately compiled macOS 27 CoreAI helper. Select model defaults and choices at runtime from the OS version, and normalize stale CoreAI selections before launch.

**Tech Stack:** SwiftUI, Foundation, Python 3.12, PyTorch MPS, Core ML, CoreAI helper, unittest, zsh packaging.

## Global Constraints

- The minimum supported operating system is macOS 26.0 on arm64/M1.
- Do not impose a new parallel-worker limit; forward the selected count unchanged.
- CoreAI remains available only on macOS 27 and newer.
- macOS 26 defaults to PyTorch/MPS restoration and Core ML detection.
